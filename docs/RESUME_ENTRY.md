## LinkedIn / Portfolio Description

**FinGuard AI: Enterprise Loan Processing & AI Governance Platform**

FinGuard AI is a comprehensive enterprise application built to simulate a modern fintech environment. It combines a robust Node.js backend with an interactive React frontend and a Python-based machine learning service.

**Key Features:**

- **AI-Powered Risk Assessment**: Integrates a Scikit-learn Random Forest model via a FastAPI microservice to instantly assess loan applications.
- **Model Governance & Explainability**: Dedicated dashboards for tracking Model Registry, visualizing SHAP feature importance (positive/negative impacts), and monitoring PSI drift across time to detect data distribution shifts.
- **Fraud Operations**: Centralized real-time monitoring of fraud alerts, SLAs, and case management with clear prioritization metrics.
- **Premium User Experience**: Crafted a visually stunning interface using custom CSS properties (glassmorphism, subtle animations) and Tailwind CSS, mirroring top-tier SaaS products like Stripe and Vercel.

**Tech Stack**: TypeScript, React, Vite, Node.js, Express, MongoDB, Python, FastAPI, Scikit-learn, Tailwind CSS, Recharts.
